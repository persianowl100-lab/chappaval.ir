# چاپ اول

## چرا ظاهر بهم می‌ریخت؟
اگر فایل HTML را مستقیم با دوبل‌کلیک باز کنید، گاهی مسیر CSS درست لود نمی‌شود.
الان هدر و فوتر داخل خود صفحات هستند و باید درست دیده شوند.

## تست
1. کل پوشه را یکجا نگه دارید (ساختار را به هم نزنید)
2. بهتر است با سرور محلی:
   python3 -m http.server 8080
   بعد: http://localhost:8080

## گیت‌هاب
کل همین پوشه را آپلود کنید. Pages را روشن کنید.

## ویرایش هدر/فوتر
هنوز فایل‌های partials/ برای مرجع هستند.
بعد از تغییر partials، دوباره باید در صفحات کپی شوند
(یا بگویید تا اسکریپت ساخت برایتان بزنم).
