# چاپ اول

## تست روی کامپیوتر
```
cd site
python3 -m http.server 8080
```
بعد برو به: http://localhost:8080

## گیت‌هاب
محتوای پوشه site را آپلود کن. Pages را روشن کن.
سایت را با https باز کن (نه با دوبل‌کلیک روی فایل).

## ویرایش
- هدر: partials/header.html
- فوتر: partials/footer.html
- اسلایدر خانه: partials/hero.html
